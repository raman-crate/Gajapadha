# GAJAPADHA | Large-Size Footwear Marketplace & 3D Bespoke Studio

> **Anatomically engineered footwear and artisan shoe maker showcase for sizes UK 11 to UK 15.**

GAJAPADHA connects buyers with verified large-size footwear from master shoemakers across India (Agra, Ambur, Kutch, Jamnagar, and Andhra Pradesh) and features an interactive **Three.js 3D Customizer** calibrated on internal millimeter lasts.

---

## 🌟 Key Features

1. **Artisan Shoe Maker Showcase Drop**:
   - Curated collections of authentic Indian heritage sneakers (Ajrakh block-print, Pochampally Ikat, Bandhani tie-dye, Kalamkari floral).
   - Detailed artisan studio credits, craft stories, and verified millimeter dimensions.

2. **Dual-Action Buyer Experience**:
   - **Buy Maker Edition**: Direct purchase of authentic artisan releases in UK 11–15 with modular insole tuning.
   - **Custom 3D Studio**: Real-time 360° 3D customizer across 7 shoe zones (vamp, quarter, heel, laces, tongue, midsole, outsole) with custom color picker, monogramming, and lighting modes.

3. **Millimeter Fit Passport**:
   - Biometric Wall-to-Book foot sizing calculator (280mm–335mm).
   - Modular footbed pairing (3mm Slim for 2E/4E wide feet, 5mm Standard, 8mm Volume-Reducer for lean feet).
   - Cross-brand size translation (Nike, Adidas, Bata, Woodland).

4. **Makers Showcase Submission Portal**:
   - Dedicated portal for independent shoemakers to exhibit new designs, set last specifications, and receive on-demand orders.

## 🚀 How to Run Locally

### Option A: Direct Open
Double-click `index.html` to open in any web browser.

### Option B: Local HTTP Server (Python)
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
